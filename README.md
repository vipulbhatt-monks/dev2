# beebot-ai

## Overview
This repository contains a Vite + React + TypeScript frontend and two backend components:

- A Node/TypeScript server (`server.ts`) used for the app's "audio mode" backend.
- A Python FastAPI backend in `api/` (runs on port `8000` by default).

Entry folder for development is `dev2`.

## Prerequisites
- Node.js (npm)
- Python 3.10+

Version checks:

```bash
node --version
npm --version
python --version
```

## Setup

### 1) Install frontend/server dependencies
From `dev2`:

```bash
npm install
```

### 2) Configure environment variables
- Frontend/Node server env file: `dev2/.env`
- Python API env template: `dev2/api/.env.example` (copy to `dev2/api/.env` and fill values)

Minimum backend environment variables:

```bash
API_KEY=...
```

Jira (current implementation uses `.env` credentials):

```bash
JIRA_BASE_URL=https://your-domain.atlassian.net
JIRA_EMAIL=...
JIRA_API_TOKEN=...
JIRA_PROJECT_KEY=...
```

## Run

You typically run 2 or 3 processes locally:

- Frontend (Vite)
- Python API (FastAPI)
- Optional: Node/TypeScript audio-mode server

### Frontend (Vite)
From `dev2`:

```bash
npm run dev
```

### Node/TypeScript server (audio mode backend)
From `dev2`:

```bash
npm run server
```

### Python API (FastAPI)
From `dev2/api`:

```bash
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --port 8000
deactivate
```

If you are using PowerShell and the activate script is blocked, run:

```bash
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then re-run `env\Scripts\activate`.

Swagger UI:

- http://localhost:8000/docs

## API Notes

- Frontend expects API base URL `http://localhost:8000` (see `services/service.ts`).

Useful endpoints:

- `POST /agent/chat` (NDJSON streaming requirements agent)
- `POST /api/jira/issues/draft-from-srs`
- `POST /api/jira/issues/publish`

## Jira Integration Notes

- Draft stories are generated by AI from SRS text via `POST /api/jira/issues/draft-from-srs`.
- Publish creates issues in Jira via `POST /api/jira/issues/publish`.
- The publish payload is constructed server-side in `api/services/jira_service.py`.
- AI-generated fields currently supported:
  - `summary`
  - `description` (converted to Jira ADF)
  - `issue_type` (optional; sent as `issuetype.name` if present)
  - `labels` (optional)
- If `issue_type` is missing, backend falls back to `issuetype.id = "10004"`.

## Common Troubleshooting

- If `python -version` fails, use:
  - `python --version`
  - `python -V`
- If the backend can’t find env vars, ensure you are launching from `dev2/api` and that `dev2/.env` exists.
